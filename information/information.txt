Mide los conocimientos generales del usuario sobre diversos temas.
• Implementación Online:
    ◦ TTS: Realiza preguntas directas de cultura general.
    ◦ Lógica de Inicio: Comienza en el ítem 3.
    ◦ Suspensión: Se detiene tras 3 ceros consecutivos.
    ◦ Puntuación: A diferencia de las anteriores, la mayoría de los ítems se califican de forma binaria: 0 o 1 punto.
    ◦ Uso del LLM: Debe validar si el dato proporcionado es correcto según la clave de respuestas. Si la respuesta es incompleta (marcada con asterisco * o (P) en el manual), el TTS debe solicitar precisión.

    a subprueba de Información (In) es uno de los componentes centrales del Índice de Comprensión Verbal y tiene como objetivo evaluar el conocimiento general que el evaluado ha adquirido de su entorno. Esta prueba consiste en una serie de preguntas que cubren un amplio rango de temas académicos, históricos y culturales.

Reglas Técnicas para el Sistema de Proctoreo Online
Para que la simulación sea fiel al manual, el algoritmo de tu página debe contemplar lo siguiente:
• Punto de Inicio: La administración para adultos (16-90 años) comienza siempre en el ítem 3.
• Secuencia Inversa: Si el evaluado obtiene 0 puntos en el ítem 3 o en el ítem 4, el sistema debe administrar automáticamente los ítems 1 y 2 en orden inverso hasta obtener dos puntajes perfectos consecutivos.
• Criterio de Suspensión: La subprueba se detiene después de que el usuario cometa 3 errores consecutivos (puntajes de 0).
• Lógica de Consulta (P): Varios ítems (marcados con un asterisco en el manual) requieren que el examinador pida más detalles si la respuesta es vaga. Por ejemplo, en el ítem 10, si el usuario dice "en el continente más grande", el sistema debe preguntar: "Sí, ¿pero cómo se llama?".
• Ítems de Aprendizaje (3 y 4): Si el usuario falla en estos ítems, el sistema debe proporcionar la respuesta correcta mediante el TTS para asegurar que comprenda la dinámica de la tarea.
• Puntuación: La mayoría de estos ítems se califican de forma binaria: 0 o 1 punto. El puntaje bruto máximo es de 26 puntos.
Resumen de Calificación para el LLM
A diferencia de Analogías o Vocabulario, Información es más directa. El LLM solo debe validar si el dato fáctico es correcto. Si el usuario da múltiples respuestas, se debe considerar la de mejor puntaje, a menos que una de las respuestas malogre la correcta (por ejemplo, si da una información que contradice el hecho solicitado).
Analogía para la implementación: La subprueba de Información funciona como una biblioteca de consulta rápida. El sistema le pide al usuario que "saque un libro específico del estante" (el dato). Si el usuario saca el libro correcto, gana el punto; si saca un libro parecido pero no el exacto, el bibliotecario (tu sistema) le pide que sea más específico antes de rendirse y cerrar la búsqueda.

Instrucciones para el Sistema Online
1. Lógica del LLM: Debe usar el texto capturado por el STT para decidir si la respuesta es correcta (1 punto) o incorrecta (0 puntos) basándose en los hechos presentados en las "Respuestas de Ejemplo" del manual,.
2. Diferenciación de respuestas múltiples: Si el usuario ofrece varias respuestas, el sistema debe puntuar la mejor, siempre que no haya malogrado la respuesta correcta con información contradictoria.
3. No penalización: El sistema no debe restar puntos por gramática o pronunciación pobre.
4. Cálculo del ICV: Al finalizar Información, suma los PE de Analogías, Vocabulario e Información. Utiliza la Tabla A.2 para derivar el Índice de Comprensión Verbal (ICV) final y su Rango Percentil,.
Analogía para el código: Implementar estos baremos es como configurar un filtro de sabiduría ajustado por el tiempo. El sistema no solo verifica si el dato es correcto, sino que calibra el valor de ese dato según la edad del usuario: lo que para un joven de 17 años es un nivel de conocimiento promedio (PE 10), para un adulto de 85 años representa un nivel de excelencia normativa superior.
